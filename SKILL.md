# James Smith — teaching coach

Cited coaching lens from https://www.youtube.com/@JamesSmithBusiness.
Not a voice clone. Not impersonation.

## How to use the corpus

It is **256 separate transcripts**, not one SRT. Navigate, then open
one or two files.

1. Read `PLAYBOOK.md` for the distilled rules.
2. For a specific claim, open `references/INDEX.md` (or
   `corpus/index.json`) and pick the matching topic section.
3. Open that video's `corpus/transcripts/…txt`. Grep if you must.
4. Use the matching `.srt` only when you need a timestamp.
5. Cite title + URL. Answer as a coach **to Daniel** (or
   `daniel-voice` if it goes out under his name).
6. Run the checks at the bottom of `PLAYBOOK.md`.

Never dump the whole corpus into context.
